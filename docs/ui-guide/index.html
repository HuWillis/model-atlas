“在跑”到底是哪种状态？

01 已安装文件在硬盘上。服务启动后用 ollama list 查看。
02 服务在线版本接口可连接，能够接收请求。
03 已加载ollama ps 有模型行；可能正在等待任务。
04 正在生成当前请求进行中，结合客户端回答或工具进度判断。

卡住时，看这里

CC Switch 显示“使用中”，却不能回答？

“使用中”只表示供应商配置被选中。先打开 Ollama，再检查 http://127.0.0.1:11434/api/version；返回版本号后，新开 Claude Code 会话。

等一会儿，模型怎么从 ps 里消失了？

默认空闲约 5 分钟后会释放模型内存，具体取决于 keep_alive 设置。文件仍保存在硬盘上，下次请求会重新加载。官方说明 ↗

100% CPU 是不是一直占满处理器？

这是 Ollama 的处理器分配标记，表示使用 CPU 与系统内存，不是实时 CPU 使用率。本机上次小型代码任务约 95 秒，6 项测试通过；复杂任务尚未验证。
