# 本地控制台实测 · 2026-11-09

环境：Windows、Python 3.12、Ollama 0.40.15，使用本机已有的 `qwen3.5-coding:4b`。模型使用 CPU 推理，本次控制台加载与测试设置为 8192 token 上下文。没有下载安装新模型。

## 浏览器真实操作

通过 Edge 的 Playwright 自动化点击真实控制台按钮，没有伪造接口响应：

1. 服务未启动时，页面显示“未启动”；发送测试按钮禁用。
2. 点击启动 Ollama，版本接口恢复，模型选择自动定位 `qwen3.5-coding:4b`。
3. 点击加载模型，真实 `/api/ps` 返回驻留模型。页面报告内存约 3.1 GiB、显存 0 GiB、上下文 8192。
4. 发送 Python 列表去重请求，收到有效 Python 函数。生成期间停止服务按钮禁用。
5. 切换为 390px 窄屏，页面没有水平溢出。
6. 点击释放内存，`/api/ps` 不再列出模型。
7. 点击停止服务，Ollama 接口离线，页面恢复“未启动”。
8. 点击退出控制台，页面禁用操作；重新运行启动脚本后恢复可访问。再次运行脚本会复用现有控制台，不重复启动。

整个流程没有浏览器 JavaScript 异常。仓库内 [控制台截图](console-preview.png) 来自本次真实请求完成后的页面，不是运行状态的持续证明。

## 本次模型输出

请求：

> 用 Python 写一个函数，对字符串列表去重，保留首次出现顺序。只给出函数代码，不要解释。

回答：

```python
def remove_duplicates(lst):
    seen = set()
    result = []
    for item in lst:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
```

Ollama 返回的统计：耗时 **7.42 秒**、输出 **53 token**、生成速度 **7.77 token/s**。审阅回答后对空列表、重复元素、顺序保持和中文字符串做了 4 项检查，全部通过，输入列表未被修改。本次预先加载了模型，速度不代表冷启动、长上下文或复杂编程任务。

这次测试只要求生成函数，没有调用 Claude Code 修改项目文件；此前的真实文件编辑验证见 [原实测记录](validation-2026-11-09.md)。
